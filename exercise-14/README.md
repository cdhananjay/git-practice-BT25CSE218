# Exercise 14 – Collaborate in Pairs

## Objective
Create a feature branch, add/improve a script, test it, push, open a pull request, review and merge.

## Script
`calculator.sh` – A simple calculator that supports +, -, *, / operations with input validation.

## Commands Used
```bash
git switch -c feature/calculator
# create calculator.sh
bash calculator.sh
git add calculator.sh
git commit -m "Add calculator script for collaboration"
git push -u origin feature/calculator
# Open PR on GitHub, review, merge
```
