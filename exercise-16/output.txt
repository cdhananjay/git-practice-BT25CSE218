=== VS Code Source Control Workflow ===

Step 1: Initialize Repository
- Open VS Code > File > Open Folder > select git-vscode-lab
- Click Source Control (Ctrl+Shift+G) > Initialize Repository
- Branch shows as "main" in status bar

Step 2: Create and Commit First File
- Create hello-vscode.py in Explorer
- File appears under "Changes" in Source Control
- Click "+" to stage the file (moves to "Staged Changes")
- Enter commit message: "Add hello-vscode script"
- Click Commit (checkmark)

Step 3: Edit and Commit Again
- Edit hello-vscode.py to add more functionality
- Click file in Changes to view diff
- Stage and commit with message: "Improve hello-vscode script"

Step 4: Create and Merge Feature Branch
- Click branch name in status bar > Create New Branch > "feature/update"
- Add updates to the file
- Stage and commit
- Switch back to main (click branch name > main)
- Command Palette > Git: Merge Branch > feature/update

Step 5: Verify in Terminal
$ git log --oneline
a1b2c3d (HEAD -> main) Merge branch 'feature/update'
b2c3d4e Add updates via feature branch
c3d4e5f Improve hello-vscode script
d4e5f6a Add hello-vscode script

=== VS Code Actions vs Terminal Equivalents ===
| VS Code Action         | Terminal Equivalent            |
|------------------------|--------------------------------|
| Stage Changes (+)      | git add FILE                   |
| Unstage Changes (-)    | git restore --staged FILE      |
| Commit                 | git commit -m "message"        |
| Discard Changes        | git restore FILE               |
| View file diff         | git diff / git diff --staged   |
