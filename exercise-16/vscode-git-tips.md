# VS Code Git Tips

## Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+G` | Open Source Control panel |
| `Ctrl+Shift+P` | Open Command Palette |
| `Ctrl+Enter` | Commit (when in Source Control message box) |

## Useful Command Palette Actions
- `Git: Clone` – Clone a repository from URL
- `Git: Create Branch` – Create a new branch
- `Git: Merge Branch` – Merge a branch into current
- `Git: Fetch` – Fetch from remote
- `Git: Pull` – Pull from remote
- `Git: Push` – Push to remote

## Conflict Resolution Tips
1. Always read both sides before choosing
2. "Accept Both" may create duplicates – review the result
3. Use the 3-way Merge Editor for complex conflicts
4. Test the resolved file before committing
