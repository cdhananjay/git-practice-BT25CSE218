# Exercise 02 – Create a Repository

## Objective
Initialize a repository on `main`. Create `README.md` with name, roll number and project title. Stage, commit, and display `git status` and `git log --oneline`.

## Commands Used
```bash
mkdir git-assignment-BT25CSE218
cd git-assignment-BT25CSE218
git init -b main
# Create README.md with name, roll number and project title
git add README.md
git commit -m "Add lab introduction"
git status
git log --oneline
```
