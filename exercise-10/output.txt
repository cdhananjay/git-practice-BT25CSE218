=== Step 1: Modify a tracked file and stage it ===
$ echo "Practice edit - to be discarded" >> README.md
$ git add README.md
$ git status
On branch main
Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
        modified:   README.md

=== Step 2: Unstage while keeping the edit ===
$ git restore --staged README.md
$ git status --short
 M README.md

(The file is modified in the working tree but NOT staged)

=== Step 3: Display the diff ===
$ git diff
diff --git a/README.md b/README.md
--- a/README.md
+++ b/README.md
@@ -4,3 +4,4 @@
+Practice edit - to be discarded

=== Step 4: Discard the practice edit ===
$ git restore README.md
$ git status
On branch main
nothing to commit, working tree clean

(The practice edit has been completely discarded)
