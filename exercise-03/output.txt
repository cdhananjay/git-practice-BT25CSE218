=== Version 2 (second commit - empty input handling) ===

$ cat greet.sh
#!/bin/bash
read -p "Enter your name: " name
if [ -z "$name" ]; then
    echo "Hello, stranger! Please provide your name next time."
else
    echo "Hello, $name! Welcome to Git Lab."
fi

$ bash greet.sh
Enter your name: Dhananjay
Hello, Dhananjay! Welcome to Git Lab.

$ bash greet.sh
Enter your name: 
Hello, stranger! Please provide your name next time.

$ git add greet.sh
$ git commit -m "Add input validation to greeting script"
