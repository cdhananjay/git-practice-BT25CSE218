# Exercise 17 – Resolve a Conflict in VS Code

## Objective
Create conflicting changes on two branches. Use VS Code's inline conflict actions to resolve. Save, stage, commit, and show clean status.

## Conflict Details
- **Current (main)**: `Lab setting: in-person only`
- **Incoming (feature)**: `Lab setting: online only`
- **Resolution**: `Lab setting: hybrid (both online and in-person)`

## VS Code Conflict Resolution Steps
1. Open conflicted file from **Merge Changes** in Source Control
2. VS Code highlights conflict with colored blocks
3. Options: Accept Current / Accept Incoming / Accept Both / Compare
4. Manually edit for the best resolution
5. Remove all conflict markers, save
6. Stage and commit to complete merge
